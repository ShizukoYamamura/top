Z-Sector Playtest — Mod Kit Early Access

Early access to the Z-Sector Mod Kit for Playtest participants. This page is unlisted and intended for direct links from Steam Guides only.

Overview

We have prepared the Z-Sector Mod Kit, a custom map authoring tool for Z-Sector. At full release, the Mod Kit will ship with the game as a free Steam tool. During Playtest, you can download it early from this page.

What you can do

  • Create custom maps in Unity
  • Validate and package maps
  • Upload maps to the Steam Workshop
  • Playtest mods can be used in the full game (re-upload required)

Download

Download the Mod Kit from the link below.

Download Mod Kit (Google Drive)

Distribution note

After the full release, install the official Mod Kit from Steam. This Google Drive build is temporary for Playtest only.

Requirements

  • Own Z-Sector Playtest on Steam
  • Unity Hub and Unity Editor 6000.4.11f1
  • Steam client running while uploading
  • Enough free disk space for the Unity project cache

Setup

  1. Download the ZIP from the link above and extract it to any folder
  2. Install Unity Editor 6000.4.11f1 through Unity Hub
  3. Run LaunchModKit.bat to launch the Mod Kit (recommended)
  4. Or add the extracted folder in Unity Hub via Add and open it

Tip

On first launch, the template scene Assets/Maps/CustomMap.unity opens automatically. For full instructions, see the bundled docs/USER_GUIDE.md and README.md.

Important — migrating to the full game

Map data (scenes and packages) created during Playtest can be used in the full release as-is. To publish on the full-game Workshop, you must upload again using the official Mod Kit that ships with the release. Playtest Workshop items are not automatically carried over.

Prohibited Map Content

The validator rejects maps that contain:

  • Custom scripts or DLLs
  • Networking components such as NetworkObject
  • Camera, AudioListener, or EventSystem
  • Executables or native plugins

Submit only static terrain, decorations, spawn markers, and baked NavMesh data.

Z-Sector Playtest — MOD Kit 先行配布

Playtest参加者向けに、カスタムマップ制作ツール「Z-Sector Mod Kit」を先行公開しています。 本ページはSteamガイドからの直リンク専用（非公開）です。

概要

Z-Sector用のカスタムマップ制作ツールMod Kitを作成しました。 本編リリース時には、ゲーム付属の無料SteamツールとしてMOD Kitを配布予定です。 Playtest期間中は、その前倒しとして本ページからダウンロードできます。

できること

  • Unity上でカスタムマップを作成
  • マップの検証・パッケージ化
  • Steam Workshopへのアップロード
  • Playtestで作ったMODは本編でも利用可能（再アップロードが必要）

ダウンロード

以下のリンクからMod Kitをダウンロードしてください。

Mod Kit をダウンロード（Google Drive）

配布について

本編リリース後はSteamから正式版MOD Kitをインストールしてください。 Playtest用のDrive配布は一時的なものです。

必要な環境

  • SteamでZ-Sector Playtestを所有していること
  • Unity Hubと Unity Editor 6000.4.11f1
  • アップロード時はSteamクライアントを起動していること
  • 十分なディスク空き容量（Unityプロジェクトキャッシュ用）

セットアップ手順

  1. 上記リンクからZIPをダウンロードし、任意のフォルダへ展開
  2. Unity Hubに Editor 6000.4.11f1 をインストール
  3. LaunchModKit.bat を実行してMod Kitを起動（推奨）
  4. または Unity Hub の Add から展開フォルダを追加して開く

ヒント

初回起動時はテンプレートシーン Assets/Maps/CustomMap.unity が自動で開きます。 詳しい作り方は同梱の docs/USER_GUIDE.md および README.md を参照してください。

重要 — 本編移行時

Playtest期間中に作ったマップデータ（シーン・パッケージ）は本編でもそのまま使えます。 ただし、本編のWorkshopへ公開するには、本編付属の正式版MOD Kitから再度アップロードしてください。 Playtest用の投稿をそのまま本編Workshopに引き継ぐことはできません。

禁止事項（マップ内容）

検証時に以下が含まれるマップは拒否されます。

  • カスタムスクリプトやDLL
  • NetworkObject などのネットワーキングコンポーネント
  • Camera / AudioListener / EventSystem
  • 実行ファイルやネイティブプラグイン

静的な地形・装飾・スポーン地点・ベイク済みNavMeshのみを投稿してください。
